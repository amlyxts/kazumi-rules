# kazumi-rules

Kazumi 自用规则仓库 — 16 个经「搜索+章节」全链路体检通过的规则
（源: Predidit/KazumiRules, 体检日期 2026-11-07, 关键词=海贼王）。

## 用法
App → 设置 → 代理 → 规则仓库 → 添加:
```
https://raw.githubusercontent.com/amlyxts/kazumi-rules/main/
```
然后在插件市场右上角切换仓库即可安装。
